Ontario Building Code Requirements for Deck Railings

Deck railings play an important role in protecting occupants and improving overall safety. In Ontario, railing requirements depend on deck height, stair configuration, and the intended use of the structure. Proper railing height, baluster spacing, load resistance, and attachment methods must comply with applicable building code requirements.

As experienced deck railing contractors, we stay up to date with current building standards and installation requirements. Our team helps homeowners understand code requirements while ensuring that every railing system is designed and installed with safety and compliance in mind.

Frequently Asked Questions

What height must deck railings be in Toronto?

Ontario Building Code requires railings on decks over 600mm (24") above grade. For decks above 1.8m, railings must be at least 1,070mm (42") high.

How much do deck railings cost?

Aluminum railings start around $90–$130 per linear foot installed. Glass railings range from $150–$250/ft. We provide free quotes.

How long does railing installation take?

Most residential railing projects are completed in 1–2 days.

Can you replace just part of my railing?

Yes — we do partial repairs and full replacements. We match existing styles where possible.

Do railings need a permit?

Railing replacement on an existing permitted deck usually doesn't require a new permit. New deck + railing builds do. We handle all permits.
