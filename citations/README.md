# aMaximum Construction — Citation Pack

Готовый набор материалов для регистрации в локальных каталогах (citations) и социальных сетях.
**Главное правило consistency**: NAP (Name, Address, Phone) должен быть **идентичен** во всех источниках —
с теми же пробелами, дефисами и регистром. Любое расхождение снижает доверие Google к вашему GBP.

## Файлы

- `nap.txt` — канонический NAP (копируй as-is, без правок).
- `descriptions.md` — описания бизнеса в 5 длинах (50 / 150 / 250 / 500 / 750 символов).
- `services-list.txt` — 18 категорий услуг (для полей "Services" в GBP, Yelp, HomeStars).
- `social-bios.md` — био для соцсетей (FB / IG / LinkedIn / Twitter/X / TikTok / YouTube).
- `directory-checklist.md` — приоритизированный список каталогов с прямыми ссылками на формы добавления.
- `jsonld-localbusiness.json` — drop-in JSON-LD schema (вставить в `<head>` главной страницы для homepage).
- `gbp-categories.md` — рекомендованные категории Google Business Profile.

## Порядок действий

1. **Сначала Google Business Profile** (https://business.google.com/) — главный источник локального трафика. Верификация открыткой 5–14 дней.
2. **Bing Places** (https://www.bingplaces.com/) — можно импортировать из GBP в 1 клик.
3. **HomeStars, Houzz, Yelp.ca** — основные нишевые каталоги для подрядчиков в Канаде.
4. **Yellow Pages Canada, Cylex, N49, BBB** — общие бизнес-каталоги.
5. Все ссылки см. в `directory-checklist.md`.

## Что НЕ делать

- ❌ Не покупай ссылки на Fiverr/PBN — Google карает.
- ❌ Не используй сервисы "submit to 500 directories" — большинство токсичные.
- ❌ Не меняй NAP между источниками. Даже "St." vs "Street" считается inconsistency.
