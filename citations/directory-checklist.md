# Citation Directory Checklist

Submit in this order. Use **identical NAP** (`nap.txt`) every time.

Legend:
- ⭐⭐⭐ — critical (do first, biggest SEO impact)
- ⭐⭐ — important (do within first month)
- ⭐ — nice to have (do later, batch in one sitting)
- 💵 — paid tier exists; free listing is fine for SEO

## Submission workflow

1. Open `nap.txt` in one window — copy fields from there. **Never retype**.
2. For each directory:
   - [ ] Create account using `care@amaximumconstruction.com`.
   - [ ] Paste NAP exactly as in `nap.txt`.
   - [ ] Use the 500-char description from `descriptions.md` (most fields accept this length).
   - [ ] Pick the closest category to **General Contractor**.
   - [ ] Add services from `services-list.txt`.
   - [ ] Upload 5–10 portfolio photos (use existing `/img/services/*.jpg`).
   - [ ] Save logo (use `/img/logo*.png`).
   - [ ] Complete verification (email / phone / postcard).
3. Track status in a spreadsheet: directory · date submitted · status · live URL · login email.

## Anti-patterns to avoid

- ❌ Duplicate listings — if a profile already exists (auto-scraped), **claim** it, don't create a second one.
- ❌ Different phone numbers per directory (e.g. tracking numbers) — these break citation consistency.
- ❌ Keyword stuffing the business name field ("aMaximum Construction Toronto GTA Renovation Contractor") — Google penalizes this.
- ❌ Buying "submit to 500 sites" packages — most are PBNs and toxic.
